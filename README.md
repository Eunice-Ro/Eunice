# Executive Sales Performance Dashboard

**Power BI portfolio project | Retail sales analytics | 2026**

## Project overview
This project explores sales performance for a multi-region retail dataset using interactive Microsoft Power BI dashboards. It was completed as part of a structured data analytics internship learning and assessment program. The portfolio includes an earlier sales analysis dashboard (Week 5) and a more advanced executive dashboard (Week 6).

## Business questions
- How are revenue, profit, order volume, and average order value performing?
- Which products and categories contribute most to sales and profit?
- How do sales and profitability vary by region and store?
- Which customers and customer segments contribute the most?
- How do revenue and profit change over time?

## Tools and methods
- **Power BI Desktop:** interactive reports, visuals, slicers, and drill-through pages
- **DAX:** measures for business KPIs, including time-based growth metrics
- **Data modeling and preparation:** working with sales, customer, product, store, returns, and date tables
- **Analysis:** comparisons by product, customer, region, store, and time period

## Dashboard pages and features
The Week 6 report contains seven pages. The four primary analysis views are:

1. **Executive Overview:** revenue, profit, profit margin, order count, average order value, year-over-year revenue and profit growth, month-over-month revenue growth, and revenue trend.
2. **Product Performance:** top products by revenue and profit, plus category comparisons.
3. **Regional & Store Performance:** regional revenue/profit and top-store rankings.
4. **Customer Performance:** top customers by revenue/profit and segment comparisons.

The report also incorporates interactive slicers and advanced navigation features, including drill-through, bookmarks, and dynamic titles.
